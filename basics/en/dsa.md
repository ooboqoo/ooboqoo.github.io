#### 思路描述

The key idea is to use a two-pointer approach to reduce the time complexity to O(n).
<span class="sm">关键思路是用双指针把时间复杂度降到 O(n)。</span>

We can solve this recursively by breaking the problem into smaller subproblems.
<span class="sm">可以用递归，把问题拆成更小的子问题。</span>

Dynamic programming helps avoid recomputation by storing intermediate results.
<span class="sm">动态规划通过存储中间结果避免重复计算。</span>

#### 复杂度分析

The algorithm runs in O(n log n) time and O(1) extra space.
<span class="sm">该算法时间复杂度 O(n log n)，额外空间 O(1)。</span>

In the worst case, the space complexity grows linearly with the input size.
<span class="sm">最坏情况下，空间复杂度随输入规模线性增长。</span>

#### 优化与权衡

We trade space for time by using a hash map.
<span class="sm">通过使用哈希表以空间换时间。</span>

This approach minimizes memory usage while keeping the solution efficient.
<span class="sm">这种方法在保持效率的同时尽量减少内存使用。</span>
